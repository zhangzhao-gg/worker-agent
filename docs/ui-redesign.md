# UI 重构计划：从「数据卡片」到「书桌视角」

## 设计理念

用户看到的不是 AI 的数据面板，是 AI 的书桌。
打开页面像推开一扇门——看到一张桌面，上面散落着这个人生活的痕迹。

**核心体验**：偷窥感 + 慢节奏 + 情绪氛围
**不是**：信息效率 / 数据后台 / 三栏布局

## 分阶段执行

---

### Phase 1：骨架重构（布局从卡片变桌面）

**目标**：去掉 480px 居中卡片，页面本身就是桌面，内容以独立"纸片"散落。

改动清单：
- [ ] VisitorView 外层容器去掉 `max-width: 480px` 居中，改为全屏桌面
- [ ] 内容拆成独立纸片组件：身份纸片、日记纸片、日程便签、对话纸条
- [ ] 纸片用 CSS Grid 或绝对定位散落放置（非严格网格）
- [ ] 每张纸片轻微随机旋转（-1.5deg ~ 2deg），`transform: rotate()`
- [ ] 唤醒输入区文案改为「轻敲桌面唤醒 TA...」
- [ ] 情绪展示从进度条改为旁白文字（已有 moodNarrative，去掉条形图）
- [ ] 移动端降级：纸片取消旋转，垂直堆叠

**不做**：动画、光效、物件交互

**完成标志**：页面打开不再是"一张卡片居中"，而是"桌上散落几张纸"

---

### Phase 2：氛围层（色温 + 环境暗示）

**目标**：让情绪可感知，让时间可感知。

改动清单：
- [ ] 页面色温跟随心情：mood 高 → 暖黄加强，mood 低 → 偏冷灰（CSS 变量动态切换）
- [ ] 顶部"窗户"区域：简单的渐变色块暗示时间（早=暖橙、午=白、晚=深蓝）
- [ ] 状态指示从圆点改为桌面小物件（蜡烛亮=活跃、蜡烛灭=休息、笔在转=思考中）——先用 emoji 或简单 SVG
- [ ] 纸片阴影随时间变化（光源方向微调）

**不做**：复杂 shader、粒子效果

**完成标志**：同一个工人在不同心情/时间段，页面"感觉"不一样

---

### Phase 3：思考时刻（唤醒体验升级）

**目标**：AI 思考时，是全页的焦点事件，不是底部小角落。

改动清单：
- [ ] 唤醒触发后桌面轻微 shake（CSS animation，50ms）
- [ ] 思考面板从"纸片底部"改为"从桌面中央浮起"的纸张
- [ ] 步骤文字逐字出现（打字机效果，已有 Special Elite 字体天然适配）
- [ ] 思考完成后，结果"落"到对应纸片上（日记内容刷新 + 轻微弹跳动画）
- [ ] 思考中其他纸片轻微变暗（聚焦注意力）

**完成标志**：唤醒 → 整个桌面活过来 → 内容更新 → 恢复平静

---

### Phase 4：多人与对话（2人场景）

**目标**：第二个工人加入时，体验自然扩展。

改动清单：
- [ ] 桌面左上角加"切换视角"按钮（看谁的桌子）
- [ ] 对话纸条样式升级：信封隐喻，点击展开气泡
- [ ] 对话进行中时纸条有呼吸动画（对方正在说话）
- [ ] 两人共有的对话在两张桌子上都能看到

**完成标志**：2 个工人之间的对话感觉像"在传纸条"

---

## 视觉参考词

- 桌面散落感：Pinterest board / 侦探剧证据墙 / 咖啡桌上的杂志
- 纸片质感：保持现有黄皮纸 + 撕裂边缘 + 油墨 text-shadow
- 旋转角度：小！1-2deg 就够，多了像 Pinterest 剪贴簿
- 留白：大量。桌面有桌面纹理，不是空白——但物件之间要有距离感
